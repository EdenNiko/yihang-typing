# 一行 · 中日文打字练习

一款练习**中文**和**日语**打字的 Windows 桌面软件。

- 两种练习语言：日语、中文，各内置 18 篇文章（日常对话、邮件、职场、生活、随笔、新闻），也可以添加自己的文章
- 两种打字方式：
  - **输入法模式**：用平时的输入法把原文打出来
  - **按键跟打模式**：不开输入法，照着屏幕上的拼音 / 罗马字逐键敲
- 汉字上方可显示读音（日语假名、中文带声调拼音）
- 实时统计速度、击键数、正确率，练完自动保存历史成绩
- 界面支持中文 / 日本語 / English，浅色与深色两套外观

## 下载与使用（普通用户）

1. 打开本仓库右侧的 **Releases**，下载最新版本里的 `yihang-x.x.x.exe`
2. 双击运行即可，**无需安装**（便携版，可放在任意文件夹）
3. 如果 Windows 弹出“已保护你的电脑”，点 **更多信息 → 仍要运行**（软件没有数字签名，这是正常提示）

> 仅支持 Windows 10 / 11（64 位）。

## 怎么练习

1. 主页选择 **日语练习** 或 **中文练习**
2. 在左侧选分类，点一篇文章
3. 选择打字方式：
   - **输入法模式**：在当前行下方的输入框里打字，整行打对会自动跳到下一行；有错字时按 **回车** 可以带着错字继续
   - **按键跟打模式**：先把输入法切到**英文**，照着提示的拼音 / 罗马字敲键，按错不会前进
4. 倒数 3 秒后开始计时；练习中可以 **暂停**、**重来**、**退出**
5. 打完最后一行自动进入成绩页，可“再练一次”或“换一篇”

其他：
- **添加自己的文章**：文章选择页右上角「＋ 添加文章」，添加后出现在「我的文章」分类里，可编辑、删除
- **历史成绩**：主页「历史成绩」查看每次练习记录
- **设置**：主页右上角齿轮，可调整倒数秒数、外观等
- **界面语言**：主页右上角国旗按钮切换

## 从源码运行（开发者）

需要先安装 [Node.js](https://nodejs.org/)（18 及以上）。

```bash
npm install
npm start          # 启动软件
npm test           # 运行检查
npm run dist       # 打包成便携版 exe，输出在 dist/ 目录
```

> 国内网络下载 Electron 较慢时，仓库里的 `.npmrc` 已配置 npmmirror 镜像。
> 安装依赖后也可以直接双击 `启动.bat` 运行。

## 项目结构

```
main.js            Electron 主进程（窗口）
src/index.html     页面
src/app.js         主要逻辑
src/data/          内置文章（ja.js 日语、zh.js 中文）
src/i18n.js        界面三语文字
test/              检查脚本
```
